Lihle's Salon Website

1. Project Overview

Lihle's Salon is a beauty salon website designed to showcase salon services, provide information about the business, and allow customers to make appointment requests. The website aims to provide a professional, attractive, and user-friendly experience.

2. Project Objectives

- Create an attractive and professional salon website.
- Display the salon's services and prices.
- Provide information about the salon.
- Allow customers to contact the salon.
- Enable customers to submit appointment booking requests.
- Ensure the website works on both mobile phones and desktop computers.

3. Website Features

- Home Page: Welcomes visitors and introduces Lihle's Salon.
- About Us Page: Explains the salon's mission, vision, values, and background.
- Services Page: Displays hair styling, nail services, makeup, and bridal services.
- Gallery Page: Showcases beauty services and salon photos.
- Contact Page: Provides contact information and an enquiry form.
- Booking Form: Allows customers to select a service, appointment date, and time.
- Form Validation: Uses HTML and JavaScript to check required information before submission.
- Responsive Design: Uses CSS media queries to improve the layout on different screen sizes.

4. Technologies Used

- HTML5: Structures the website content.
- CSS3: Styles the website, including colours, layouts, images, and responsive design.
- JavaScript: Adds client-side form validation and interactive functionality.

7. How to Run the Website

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Ensure the HTML, CSS, and image files are in the correct locations.
4. Open "index.html" in a web browser, or use the Live Server extension in Visual Studio Code.
5. Navigate through the website using the navigation menu.
6. Test the booking and contact forms.

8. Responsive Design

The website uses CSS Flexbox, CSS Grid, and media queries to adapt the layout to different screen sizes. This helps users navigate the website on smartphones, tablets, laptops, and desktop computers.

9. Form Validation

The booking form uses HTML validation attributes such as "required", "type="email"", and "pattern". JavaScript provides additional client-side validation.


10. Future Improvements

- Connect the booking form to a database.
- Add an appointment confirmation system.
- Add online payments.
- Display customer reviews and testimonials.
- Add a salon location map.

11. Conclusion

Lihle's Salon website provides an online platform for presenting beauty services and helping customers find information about the salon. Its responsive layout, consistent colour palette, and clear navigation aim to make the website attractive, accessible, and easy to use.
